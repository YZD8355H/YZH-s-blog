# YZH的Blog — 个人技术博客 设计文档

- 日期：2026-08-06
- 状态：已获用户批准（分节确认：架构 / 页面功能 / 验证交付）

## 1. 概述

为 YZH 构建一个现代化、深色开发者风格的个人技术博客。核心理念：**Markdown 即文章** —— 写好的 `.md` 文件丢进 `content/posts/` 即发布。本机运行，将来可无成本部署为纯静态站点。

## 2. 需求（用户确认）

| 项 | 决定 |
|---|---|
| 定位 | 技术博客：编程、开发经验、教程类 |
| 部署 | 先本机使用，将来再上线 → 纯静态架构 |
| 写作 | Markdown 文件即文章 |
| 技术路线 | 方案 A：Python 自写轻量构建器 |
| 风格 | 深色主题优先的开发者风格 |
| 功能 | 标签/分类 + 归档页；站内全文搜索；关于页 + 友链页 |
| 身份 | 博客名 "YZH的Blog"，署名 "YZH" |

明确不加（YAGNI）：RSS、文章 TOC、阅读时长统计、评论系统、数学公式（后续可一个 commit 加上）。

## 3. 架构

Python 构建脚本将 Markdown 渲染为纯静态 HTML，输出到 `site/`。

依赖（uv 管理，不污染全局）：`markdown`、`pygments`、`jinja2`。

构建产物零运行时依赖：不依赖 CDN、不依赖外网，断网可完整浏览（代码高亮由 Pygments 构建时渲染）。

## 4. 目录结构

```
YZH's blog/
├── build.py              # 构建脚本：markdown → 静态 HTML
├── serve.py              # 本地预览服务器（可指定端口）
├── config.yaml           # 站点配置：博客名、署名、描述、社交链接、友链
├── content/
│   ├── posts/            # 文章目录：*.md，丢进来即发布
│   └── pages/            # 独立页面：about.md、links.md
├── templates/            # Jinja2 模板（base/index/post/archive/tag/search/page）
├── assets/               # style.css、highlight.css、search.js、图标
└── site/                 # 构建产物（纯静态，整个文件夹将来可直接部署）
```

### 文章 frontmatter（YAML）

```yaml
---
title: 文章标题            # 必填
date: 2026-08-01          # 必填，YYYY-MM-DD
tags: [Python, 教程]       # 可选
category: 开发             # 可选
summary: 一句话摘要         # 可选，缺省取正文开头
draft: true               # 可选，true 时跳过构建
---
```

### 约定

- 文件名即 URL：`2026-08-01-hello-world.md` → `/posts/2026-08-01-hello-world.html`
- 文章按日期倒序排列

## 5. 页面与功能

全局：顶部导航（标志 | 文章 | 归档 | 标签 | 关于 | 友链 | 🔍搜索框）；深色主题（#0d1117 系背景 + 强调色 + 等宽字体）；页脚（© YZH + 年份 + 社交链接）；响应式。

| 页面 | 内容 |
|---|---|
| 首页 | 文章列表：标题+日期+标签+摘要，倒序，每页 8 篇 + 页码导航 |
| 文章页 | 标题、日期、分类徽标、标签、正文（Pygments 深色高亮）、上一篇/下一篇 |
| 归档页 | 按年份分组的时间线列表 |
| 标签页 | 标签云（含文章数）；每个标签独立列表页 |

说明：`category` 为单值分类，作为文章元数据在首页列表与文章页以徽标显示；浏览入口统一走标签体系（`tags` 可多值）。
| 搜索页 | 实时全文搜索，过滤本地 `search-index.json`，结果高亮 |
| 关于/友链 | Markdown 静态内容；友链在 config.yaml 管理 |

## 6. 错误处理与验证

- frontmatter 缺字段 / YAML 格式错误 → 报错并指出文件名和行号
- 日期格式错误 → 明确报错
- `draft: true` 跳过构建（不进页面、不进索引）
- 空站（0 篇文章）可正常构建
- 构建后自动验证：内部链接死链检查、资源（CSS/JS/图片）存在性检查、slug 冲突检测

## 7. 示例内容与交付

- 生成 4 篇示例技术文章（中文排版、代码块、多标签、长文），展示全部功能，用户可删

